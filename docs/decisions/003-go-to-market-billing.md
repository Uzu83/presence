## 4. 実機検証チェックリスト（Phase 0・存続）

1. iPhone Safari で本番 URL が開く／ホーム画面追加できる  
2. 設定で OpenAI / Google / xAI キー保存→再起動後も残る  
3. テキスト: GPT 系でストリーム返信  
4. テキスト: 「調べて」で検索中表示→出典っぽい最新情報が返る（xAI 推奨）  
5. 資料: `.md` 追加→その内容について質問が当たる  
6. **GPT Live**: 話す→割り込みできる  
7. **Gemini Live**: 同上（失敗しやすい。失敗理由をメモ）  
8. **Grok Voice**: 同上＋「調べて」  
9. キー未設定エンジンで、誘導が設定タブに向く  
10. 「Plus があれば無料」等の誤解を誘う文言が画面にない  

合格ライン: 1–5 と 10 は必須。6–8 は **2/3 成功**で Phase 0 クリア。
