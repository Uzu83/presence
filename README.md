# Presence

自分の API クレジットで話す、スマホ優先の Web / PWA。

- **GPT Live · Gemini Live · Grok Voice**（三本柱）
- テキストも OpenAI / xAI 切替
- プロジェクトにファイルを置いて会話（NotebookLM 風）
- 「調べて」でウェブ検索
- 将来: Discord / Meet / Zoom 同席

## 開発

```bash
pnpm install
pnpm dev
```

検証:

```bash
pnpm check
```

## 使い方

1. 設定で OpenAI / xAI の API キーを保存（端末のみ）
2. 資料タブでプロジェクトとテキストファイルを追加
3. 会話タブでモデルを選んで話す / 音声タブでフルデュプレックス
